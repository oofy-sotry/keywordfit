# 시연 영상 시나리오 (1분 30초 안팎)

흐름: 상품 입력 → 분류 선택 → 시장·수입 차트 → 진입 판단 → AI 코멘트 근거 확인

## 녹화 전 준비

- 주소: https://keywordfit-blue.vercel.app (브라우저 폭 1280px 이상, 라이트 모드)
- **녹화 직전에 같은 상품을 한 번 미리 조회**해 둔다. 첫 AI 분류는 무료 티어라 10초 넘게 걸릴 수 있고, 두 번째부터는 캐시로 바로 나온다.
  - 분류: 상품명 입력 → 분석
  - 코멘트: "코멘트 받기"까지 한 번 눌러 두기
- 예시 상품: **텀블러** (생활용품 / HS 961700 진공 플라스크, 2026-10 기준 등급 "기회")
  - 다른 상품을 쓰려면 등급과 코멘트가 자연스러운지 미리 확인한다.
- 화면 녹화는 1080p, 마우스 포인터 표시. 자막으로 설명하거나 내레이션을 녹음한다.

## 장면

| 시간 | 화면 동작 | 말할 내용 (자막·내레이션) |
|---|---|---|
| 0:00–0:10 | 첫 화면 | "셀러가 새 상품을 들일지 정할 때 필요한 시장·수입 데이터를, 상품명 하나로 공공데이터에서 찾아 줍니다." |
| 0:10–0:25 | 입력칸에 "텀블러" → **분석** → "분류 결과"에 상품군(생활용품)과 HS코드 후보 3개 | "AI가 통계청 상품군과 관세청 HS코드 후보를 고릅니다. AI가 만든 코드는 관세청 코드표에 있는 것만 통과하고, 품명도 코드표 값으로 보여 줍니다." |
| 0:25–0:30 | 두 번째 후보를 눌렀다가 1순위로 되돌리기 (선택하면 다시 분석되는 것 보여 주기) | "후보와 상품군은 직접 바꿀 수 있습니다." |
| 0:30–0:45 | 스크롤 → 시장 섹션: 최근 월 거래액, 12개월 성장률, 24개월 차트, **기준월·출처** 표기 | "통계청 KOSIS 온라인쇼핑동향입니다. 공공데이터는 월 단위로 늦게 나오기 때문에 기준월과 출처를 항상 표시합니다." |
| 0:45–1:00 | 수입 섹션: 수입액 차트, kg당 단가 차트, 수입국 점유율 표 (중국 비중) | "관세청 수출입실적으로 이 품목이 얼마나, 어디서, kg당 얼마에 들어오는지 봅니다. 경쟁 유입과 소싱 단가의 신호입니다." |
| 1:00–1:10 | 진입 판단 배지 "기회" | "시장 성장률과 수입 증가율로 진입 등급을 매깁니다. 기준은 대표 품목 22개의 실제 분포를 보고 정했습니다." |
| 1:10–1:25 | **코멘트 받기** → 코멘트 4개 + 문장마다 근거 지표 칩 | "AI는 숫자를 직접 쓰지 않고 자리표시자만 씁니다. 숫자는 서버가 우리 데이터로 채우고, 칩으로 근거를 보여 줍니다. 자리표시자 밖에 숫자를 쓰면 그 문장은 버립니다." |
| 1:25–1:30 | 주소창의 공유 링크(`?q=텀블러&category=…&hs=…`) | "결과는 링크로 공유할 수 있습니다. 전부 무료 플랜으로 만들었습니다." |

## 녹화 후 확인

- 키·관리자 화면(Supabase, Vercel, AI Studio)이 영상에 나오지 않았는지
- 브라우저 북마크·다른 탭에 개인 정보가 보이지 않는지
- 길이 2분 이하
