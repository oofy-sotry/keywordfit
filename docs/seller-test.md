# 셀러 사용성 테스트 안내 (D6)

지인 셀러 2~3명에게 실제로 써 보게 하고, 피드백과 반영 여부를 `docs/ai-log.md` D6에 기록한다.

## 진행 방법 (1인 10~15분)

1. 링크 전달: https://keywordfit-blue.vercel.app
   - 처음 보는 사람이 설명 없이 쓸 수 있는지가 핵심 → **사용법은 먼저 설명하지 않는다**
2. 부탁할 일
   - "지금 팔고 있거나 팔아 보고 싶은 상품 2~3개를 넣어 보세요"
   - "AI 코멘트도 한 번 받아 보세요"
3. 지켜볼 것 (화면 공유나 옆에서)
   - 어디서 멈칫하는지, 무엇을 눌러 보려 하는지
   - 분류 결과(상품군·HS코드)를 이해하는지, 바꿔 보는지

## 끝나고 물어볼 질문

1. 처음 화면만 보고 무엇을 하는 서비스인지 알 수 있었나요?
2. AI가 고른 상품군·HS코드가 맞았나요? 틀렸다면 무엇이 맞나요?
3. 결과 중 실제로 도움이 된 정보는? (시장 규모 / 성장률 / 수입액 / 단가 / 수입국 / 진입 판단 / AI 코멘트)
4. 이해가 안 되거나 믿기 어려웠던 숫자·문구는?
5. 이 서비스를 다시 쓴다면 언제 쓸 것 같나요? 없으면 왜인가요?
6. 하나만 바꿀 수 있다면?

- "반영 여부"는 반영 / 보류(이유) / 반영 안 함(이유) 중 하나로. 반영했으면 커밋 해시를 적는다.
- 피드백은 들은 말을 최대한 그대로 적는다 (해석은 반영 이유 칸에).

## 알려 줄 수 있는 한계 (질문이 나오면)

- 키워드별 검색량은 공공데이터에 없어 보여 주지 않음
- 데이터는 월 단위, 1~2개월 늦게 공표됨 (화면의 "기준 월" 참고)
- 시장 규모는 상품군 전체(예: 가전·전자), 수입은 HS 품목 단위라 범위가 다름
- AI 코멘트의 수치는 AI가 쓴 게 아니라 공공데이터 값
